# Синтетичні обкладинки для перевірки Docker

`cover.jpg`, `cover.png`, `cover.webp` — власні тестові зображення 900 × 600: синє тло, жовтий прямокутник і бірюзове коло. Створені Magick.NET 15.0.0 під час PH-06; не містять фотографій людей або приватних даних. PH-07 використовує їх для перевірки всіх трьох декодерів у Linux-контейнері та точного збереження оригіналу після перезапуску.
