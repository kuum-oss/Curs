# PH-08 — календар задач, 21.10.2026

Виконано після [концепту](concepts/TASK_CALENDAR.md), створеного до коду (`93ffd7d`). [Протокол](PH08_CALENDAR_RESULTS.json), [справжні скриншоти](screenshots/calendar/README.md).

Розділ «Календар»: усі доступні активні дошки й картки; тиждень або місяць, понеділок — перший день, сьогодні/попередній/наступний період. Місяць має 42 клітинки з сусідніми датами. Фільтри — усі, без виконавця або конкретний учасник; без дедлайну — окремий список. Усі сторінки завантажуються, задачі не губляться після перших 500. Назва відкриває чинний редактор із захистом чернеток. Перетягування за ⠿ на дату зберігає лише дедлайн, у блок «Без дедлайну» — прибирає його. Escape/втрата захоплення скасовує перенесення. Щоб перенести за межі видимого періоду, відкрийте редактор дедлайну або змініть період перед наступною дією. Календар прокручується, клітинки з багатьма задачами мають власну прокрутку.

`GET /api/me/calendar?from=…&to=…&assigneeId=…&unassigned=false&offset=0&limit=500`: до 42 днів, кінець виключно, разом із картками без дати. Сервер фільтрує членство/архів/виконавця до пагінації, читає узгоджену сторінку й версії. Фото не завантажуються. `PUT /api/cards/{id}/deadline`: nullable dueDate та версії картки/дошки; спільний транзакційний шлюз BoardAccess, повторна перевірка членства, відмова для архіву. Конфлікт не перезаписує інші поля, клієнт оновлює календар і повідомляє причину. Схема незмінна: 8 міграцій, 13 таблиць.

183 тести без помилок/пропусків, після оптимізації повторно пройшли 8 календарних тестів; Release і macOS publish без попереджень. Границя періоду, пагінація, ізоляція, конфлікти, відкликання, архів, незмінність інших полів, понеділки/новий рік/високосний рік, вихід під час запиту. 17 запитів Docker API; нативний CUA перевірив місяць/тиждень/фільтр, перетягнув 22→23 жовтня, після перезапуску відкрив правильну картку з новою датою. Дату додатково звірено API. 2 власні випадкові аккаунти прибрано, demo не змінювалися, робочий том збережено.
