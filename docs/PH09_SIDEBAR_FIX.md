# PH-09 — бічна панель та іконки

Дата: 21.10.2026. Статус: виконано. Код: `94d2edf`.

## Причина та зміна

Вісім пунктів навігації та останні дошки знаходилися в одному `StackPanel` у рядку `*`. Список не обмежувався залишком висоти й малювався поверх нижнього профілю та виходу.

У `BoardWorkspaceView.axaml` панель тепер має чотири рядки: заголовок, навігація, обмежена область останніх дощок та профіль/вихід. Лише список останніх дощок має власний вертикальний `ScrollViewer`; його вміст обрізається межами області. Профіль має окремий рядок і відступ. Довгі назви залишаються скороченими з підказкою повної назви.

Символи шрифту `▦` та `▤` замінено на `PathIcon`: календар із кільцями та датами; файл із загнутим кутом. Розмір і колір узгоджені з рештою навігації.

## Перевірка

- `scripts/dotnet.sh build Curs.sln -c Release`: успішно, 0 помилок, 0 попереджень.
- `scripts/package-macos.sh`: створено актуальний `TestResults/KanbanBoard.app`.
- Нативний Avalonia-клієнт у звичайному вікні: п’ять тимчасових дощок із довгими назвами та довге ім’я користувача. Перехід від початку до кінця прокрутки змінює лише список; профіль, розділювач і вихід залишаються нижче, без накладання. Значення вертикальної прокрутки змінилося з 0 до 83.
- Іконки оглянуті на реальному екрані. Обидві кнопки відкривають відповідні сторінки: «Календар задач» і «Резервні копії та експорт».
- Після виходу прибрано лише створений для цієї перевірки аккаунт із префіксом `sidebar-check-` та його п’ять порожніх дощок. SQL: 0 таких аккаунтів; усі 4 захищені demo на місці.

[Скриншоти до та після прокрутки](screenshots/sidebar-fix/README.md).

Обсяг перевірки: компонування XAML та нативна взаємодія. Повний серверний набір тестів не повторювався, сервер і схема БД не змінювалися. Мінімальний розмір вікна окремо не підтверджений: інструмент не змінив геометрію при спробі resize; перевірено фактичне звичайне вікно. Локальні журнали збірки — в ігнорованому `TestResults`.
