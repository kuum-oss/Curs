Справжні знімки Avalonia `.app`, Docker API, MSSQL. Окремі випадкові тестові користувачі й дошка, усі прибрані після перевірки; demo не змінювалися. Це не згенерований концепт.

- [03-card-target.jpg](03-card-target.jpg): перехід із плитки відкрив редактор «Підготувати презентацію».

Перевірте доступ до дошки.` при натисканні раніше завантаженої плитки одразу після відкликання; це спостереження accessibility, окремого скриншота помилки немає. API-звірка підтвердила третє повідомлення з точним ID картки та без тексту чернетки. [Повний протокол](../../PH08_CHAT_CARDS_RESULTS.json).
