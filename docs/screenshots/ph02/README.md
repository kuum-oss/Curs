# Фактичні екрани PH-02

Скриншоти нативного Avalonia-застосунку від 11.10.2026. Це виконаний інтерфейс, а не згенеровані ескізи. Тестовий обліковий запис використовував окрему тимчасову БД, яку прибрано після перевірки.

| Зображення | Що підтверджує |
| --- | --- |
| [Вхід](login.jpg) | Поля й читабельне оформлення |
| [Реєстрація](register.jpg) | Ім'я, email та маскований пароль |
| [Помилка входу](invalid-login.jpg) | Повідомлення, збереження email та очищення пароля |
| [Авторизований користувач](signed-in.jpg) | Дані користувача та успішний захищений запит |
| [Вихід](logout.jpg) | Повернення до порожньої форми входу |
| [Повторний запуск](restarted.jpg) | Сесія не відновлюється з диска |

Повний результат — у [звіті PH-02](../../PH02_AUTHENTICATION.md) та [протоколі](../../PH02_RESULTS.json). Керування дошками з початкового екрана реалізується в PH-03.
