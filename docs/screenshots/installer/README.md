# Нативна перевірка майстра встановлення

03.11.2026, Avalonia/macOS, Apple Silicon. Знімок зроблено з локального пакета для перевірки компонування. Для нього використано окремий ідентифікатор preview-програми; звичайний клієнт і його сеанс не змінювалися.

| Файл | Перевірений стан |
| --- | --- |
| [01-first-launch.jpg](01-first-launch.jpg) | Початковий екран: три етапи, пояснення локальної підготовки, вимкнена згода з умовами SQL Server Developer, недоступна до згоди кнопка підготовки |

Під час цієї перевірки умови не приймалися, підготовка сервера не запускалася. Знімок підтверджує вигляд першого екрана, а не проходження встановлення Docker або готовність API/БД. Preview-пакет має тестові метадані компонування і не призначений для публікації.

Окремий режим `--verify-startup` створює нативний інтерфейс і завершується без Docker, завантаження серверних компонентів, збереженого сеансу чи звернень до БД. Усі перевірки зі справжнім SQL для цієї фази виконуються на тимчасових серверах GitHub Actions. Локальна Docker-БД не змінювалася.
