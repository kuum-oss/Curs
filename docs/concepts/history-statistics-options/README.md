# Історія та статистика — чотири варіанти навігації

Дата: 21.10.2026. Статус: **на вибір користувача; реалізацію не розпочато**.

За поточною вказівкою спочатку порівнюються чотири концепт-арти. Якщо жоден не підходить, розширення скасовується. Після вибору — детальні концепти відповідних екранів, потім реалізація погодженого обсягу. Цей пакет не є завершенням фази розробки.

| № | Концепт | Зручність і компроміс |
| --- | --- | --- |
| 1 | [Вкладки дошки](01-board-tabs.png): Дошка / Історія / Статистика | Усі режими одразу видно, один клік для переходу. Потрібен окремий рядок вкладок. |
| 2 | [Бічна панель](02-side-panel.png): кнопка Огляд, історія/статистика справа | Зміни видно поруч із задачами. Відкрита панель зменшує ширину дошки; у вузькому вікні має накладатися, а не стискати всі колонки. |
| 3 | [Огляд проєкту](03-project-overview.png): показники та останні події разом | Зручно для оцінки стану проєкту. Огляд — окремий режим, дошка має залишатися доступною без примусового переходу через нього. |
| 4 | [Компактний перемикач](04-view-switcher.png): Дошка / Історія / Статистика в одному меню | Заощаджує місце у звичайному вікні, але приховані режими помітні менше і вимагають двох кліків. |

Спільні пропозиції: групи «Робота» / «Інструменти» в бічній навігації без нових глобальних розділів; одна кнопка фільтрів з лічильником; вторинні адміністративні дії в меню «…»; профіль та вихід відокремлені від прокрутки останніх дощок. Це також потребує вибору користувача, автоматично не застосовується.

Рекомендація: навігація варіанта 1, вміст статистики за варіантом 3. У деталях картки — локальні вкладки «Деталі» / «Історія» без додаткових глобальних кнопок. Детальні екрани картки й повної історії ще не генерувалися.

## Походження та перевірка

Чотири окремі зображення створені вбудованим **imagegen**. Референси: [ескіз дошки](../../sketches/kanban-board.png) та [актуальна бічна панель](../../screenshots/sidebar-fix/02-sidebar-bottom.jpg). Точні [промпти](PROMPTS.md) збережені поряд. Зображення оглянуті: світла тема, бірюзовий акцент, картки та різні способи навігації присутні у всіх чотирьох варіантах. Оригінали залишені в каталозі generated_images, копії — тут.

Це згенеровані концепти, не скриншоти готової функції. Значення статистики, імена й події ілюстративні та не є результатами вимірювань. Прев’ю та стрілки-пояснення у варіантах 1/4 показують ідею й не зобов’язують додавати постійні панелі до продукту. Декоративні написи, точність текстів, узгодженість підсумків графіків і поведінка на малих розмірах потребують уточнення в деталізованому погодженому дизайні.

Код, база даних, поточна навігація та статуси виконання фаз не змінювалися. Збірка для пакета растрових ескізів не потрібна.
