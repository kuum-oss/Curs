# Історія та статистика — чотири варіанти навігації

Дата: 21.10.2026. Огляд чотирьох варіантів компонування. Підсумковий дизайн поєднує вкладки варіанта 1, огляд варіанта 3 та праву панель варіанта 2. [Детальні макети](../history-statistics-selected/README.md).

| № | Концепт | Зручність і компроміс |
| --- | --- | --- |
| 1 | [Вкладки дошки](01-board-tabs.png): Дошка / Історія / Статистика | Усі режими одразу видно, один клік для переходу. Потрібен окремий рядок вкладок. |
| 2 | [Бічна панель](02-side-panel.png): кнопка Огляд, історія/статистика справа | Зміни видно поруч із задачами. Відкрита панель зменшує ширину дошки; у вузькому вікні має накладатися, а не стискати всі колонки. |
| 3 | [Огляд проєкту](03-project-overview.png): показники та останні події разом | Зручно для оцінки стану проєкту. Огляд — окремий режим, дошка має залишатися доступною без примусового переходу через нього. |
| 4 | [Компактний перемикач](04-view-switcher.png): Дошка / Історія / Статистика в одному меню | Заощаджує місце у звичайному вікні, але приховані режими помітні менше і вимагають двох кліків. |

Спільні елементи: групи «Робота» / «Інструменти» в бічній навігації без нових глобальних розділів; одна кнопка фільтрів з лічильником; вторинні адміністративні дії в меню «…»; профіль та вихід відокремлені від прокрутки останніх дощок.

У підсумковому дизайні використано навігацію варіанта 1 та вміст огляду варіанта 3. У деталях картки — локальні вкладки «Деталі» / «Історія» без додаткових глобальних кнопок.

## Візуальні орієнтири

[Ескіз дошки](../../sketches/kanban-board.png) та [бічна панель](../../screenshots/sidebar-fix/02-sidebar-bottom.jpg). Світла тема, бірюзовий акцент і картки збережені в усіх чотирьох варіантах.

Це макети, а не скриншоти готової функції. Значення статистики, імена й події ілюстративні та не є результатами вимірювань. Прев’ю та стрілки у варіантах 1/4 пояснюють ідею компонування. Результати реалізації наведено у [PH-10](../../PH10_HISTORY_STATISTICS.md).
