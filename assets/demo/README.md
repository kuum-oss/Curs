| Файл | Зображення |
| --- | --- |
| `workspace.png` | Робочий стіл із ноутбуком, кавою, рослиною та блокнотом біля вікна. |

## Аватари вигаданих учасників

Чотири квадратні портрети 1254×1254, кожен до 5 МіБ. Учасники вигадані; фото не представляють реальних власників акаунтів. Центральне розміщення обличчя залишає місце для круглого кадрування.

- `avatar-anastasiia.png` — жінка з каштановим волоссям до плечей у світлій блузі.
- `avatar-olena.png` — жінка з темним коротким волоссям у блакитній сорочці.
- `avatar-dmytro.png` — чоловік із коротким темним волоссям і бородою в темній сорочці.
- `avatar-iryna.png` — жінка із зібраним русявим волоссям у зеленому светрі.

Скрипт `scripts/seed-demo.py` створює лише демонстраційні дані через локальний API; випадковий пароль та ID зберігаються у виключеному з Git `TestResults/ph08-demo.json`.
