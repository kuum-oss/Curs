# KanbanBoard — курсова робота

Клієнт-серверна десктопна система для командного планування завдань за Kanban-методологією. Користувачі працюють зі спільними дошками, колонками та картками через клієнт Avalonia UI.

| [План реалізації](docs/IMPLEMENTATION.md) | Архітектура, модель БД, API, інтерфейс, Docker та етапи розробки |

## Технології

| Компонент | Технологія |
| --- | --- |
| Десктопний клієнт | C#, Avalonia UI, MVVM |
| Сервер | ASP.NET Core Web API |
| База даних | Microsoft SQL Server 2022 |
| Доступ до даних | Entity Framework Core |
| Автентифікація | JWT, BCrypt |
| Інфраструктура | Docker, Docker Compose |
| Середовище розробки | Rider, macOS |

## Поточний стан

Стан на 10.10.2026: у рішенні `Curs.sln` є початковий десктопний проєкт `Curs/Curs.csproj`, який використовує .NET 10 та Avalonia 11.3.12. Головне вікно містить стандартне привітання Avalonia.

API, модель даних, автентифікація, дошки, Docker-конфігурація та тести ще не реалізовані. Документи описують вимоги й заплановану реалізацію, а не завершені функції.

## Межі проєкту

- Єдиний користувацький інтерфейс — десктопний застосунок Avalonia.
- Розгортання локальне; хмарний деплой не входить до завдання.
- Сервер і база даних мають запускатися через Docker Compose.
- Десктопний клієнт запускається як нативний застосунок. Це запропоноване уточнення вимоги про запуск «усіх компонентів» у Docker, яке потрібно погодити перед реалізацією інфраструктури.

Послідовність робіт і питання, які залишаються відкритими, наведені в [плані реалізації](docs/IMPLEMENTATION.md).
