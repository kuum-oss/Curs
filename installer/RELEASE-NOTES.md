Десктопний KanbanBoard для локального використання.

## Завантаження

- **Windows x64:** файл `windows-x64-setup.exe`; встановлення для поточного користувача, ярлик і запуск. ZIP — переносний варіант.
- **Mac з Apple Silicon:** `macos-apple-silicon.dmg` або ZIP з `KanbanBoard.app`.
- **Mac з Intel:** `macos-intel.dmg` або відповідний ZIP.

Відкрийте програму й пройдіть майстер першого запуску. Він перевіряє Docker Desktop, завантажує готовий сервер і готує локальну базу. Окремі .NET SDK, Python та вихідний код не потрібні.

Якщо Docker відсутній, майстер відкриває офіційний установник. Системні дозволи, ліцензійні умови, налаштування віртуалізації та можливе перезавантаження Windows виконуються у штатних вікнах. Потрібні інтернет, місце для Docker/образів і ресурси, зазначені у вимогах Docker Desktop. SQL Server Developer призначений для розробки, тестування й демонстрацій, а не production-використання.

Архіви `kanbanboard-server-linux-*.tar.gz` завантажує майстер; вручну відкривати їх не потрібно. `SHA256SUMS` містить контрольні суми всіх файлів релізу.

Mac-пакети мають ad-hoc підпис цілісності та **не мають Apple Developer ID / notarization**. Windows-установник не має комерційного підпису видавця. ОС може вимагати окреме підтвердження запуску; пакети не змінюють налаштування Gatekeeper або SmartScreen.

Дані зберігаються локально й не видаляються при звичайному оновленні або видаленні клієнта. Детальна інструкція: [RELEASES.md](https://github.com/kuum-oss/Curs/blob/main/docs/RELEASES.md).
